# SolidJS Frontend

Frontend de referencia inicial do Stacks Base.

## Escopo Atual

- Registro
- Login
- Logout
- users/me
- Forgot password
- Reset password
- Change password
- Dashboard protegido
- Gestao administrativa de usuarios
- Auditoria administrativa
- Exportacao CSV, XLSX e PDF

## Requisitos locais

- Node.js 20+
- npm 11+
- Backend Go rodando em http://127.0.0.1:8080

## Execucao

1. Copie as variaveis de `.env.example`.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Para validacao local use tambem `npm test` e `npm run build`.
